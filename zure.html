ABOUT / 仕様メモ
テンポ: 各トラックは独立した連続BPMを持つ。スケジューラはWeb Audioの オーディオクロック基準（lookahead方式）で、1ステップの長さを テンポ曲線の数値積分（シンプソン則）で求めるため、テンポが動いている最中でも 位相がずれない。
BPMの変更: つまみ・手入力・MIDIどれで変えても即座には跳ばず、 CATCH-UP CONSOLE の CATCH RATE / CURVE に従って現在の再生テンポから グライドする（最大120秒）。グライド中にもう一度動かすと、その地点から 新しい目標へ再計画される。停止中は即時反映。
ピッチ: シンセ音源はシーケンサークロックの変速なのでピッチ不変。 サンプルは playbackRate = BPM / BASE BPM のテープ方式で、 テンポの揺れがそのままピッチのうねりになる。サンプルの TUNE つまみは BPMそのものを動かす（チューニング＝テンポの一部）。 音声ファイルにはBPM情報が無いため、読み込み時の BASE BPM は 120 とし、 FIT LOOP（サンプル全体＝ループ長とみなして算出）か手入力で合わせる。
音色エディット: 各トラックの VOICE EDIT で、シンセボイスごとに 波形（AUTO/SIN/TRI/SQR/SAW）・ATK（アタック）・ピッチ（コードはカットオフ）・ ディケイ・サスティン、ドラムはさらに TONE を編集できる。AUTO はライブラリ 本来の波形。SUS を上げた行はゲート式: 連続して塗った（クリックした） セルの並びがひとつのノートになり、並びの最初で発音、最後のセルの直後で リリースされる。SUS=0 なら従来どおりセルごとのワンショット。各行はモノで、 新しいノートは前の音をチョーク（CH/OH は相互）。停止時と8秒の上限でも解放。
CHORD の音作り（簡易 Prophet-5）: TONE 行の下の OSC B 行で 2つ目のオシレータを混ぜられる。波形（AUTOはライブラリ既定）、 HARM（倍音比 ×0.5〜×4、Bの音程）、MIX（A:B バランス）、 P.MOD（ポリモジュレーション — B の波形で A の周波数を揺らす。上げると 金属的・ベル的な倍音が出る）、NOISE（ミキサーにホワイトノイズを足す）。 デフォルトは従来の音色相当（808: sine+tri×2 / 909: 2xSAW デチューン）。
ドラム専用パラメータ: TONE はアタックの硬さと明るさ（0.5=原音、 ±12dB のハイシェルフ+アタック時間の伸縮）。スネアの SNAPPY は響き線の ノイズ量（0でタムのようなトーンだけの音）。KIT の ACCENT は全体の音量に メリハリを付けつつ、アナログ回路よろしくキックの歪み（サチュレーション）と アタック感も連動して変わる。
SHIFT（ずらし）: 各トラック上部の ◀BAR ◀拍 拍▶ BAR▶ で、 ループ位置を1拍/1小節ぶん一瞬でずらす。タイミンググリッドは触らず パターンの読み出し位置だけが跳ぶので、音は途切れず、ズレたまま維持される。
WANDER: 各トラック上部の往復機。ONにした時点のBPMをホームとして、 DEST との間を行ったり来たりする。到達すると DWELL 秒だけ停滞し、 TRAVEL 秒かけて元のBPMへ向かう（グライドと同じ機構なのでステップは正確）。 つまみや CATCH で手動介入すると WANDER は自動で外れる。 優先順位は CATCH ＞ WANDER: CATCH をかけると追う側・追われる マスター双方の WANDER が止まり、CATCH 中のトラック（および CATCH の 対象になっているマスター）には WANDER を新たに掛けられない。
操作の要点: CATCH RATE は合流にかける時間（左=速い/右=遅い、 追従の途中で回すと再計画）。BPM SYNC はテンポのみ一致で小節頭はズレたまま並走、 PHASE SYNC は目標BPMを一瞬追い越して小節頭を合わせロックする。 ヘッダーの A–D でトラックの ON/OFF。グリッドはクリックのほか 押しながらスライドで連続入力（最初のセルで ON/OFF が決まる）。 トラックカードをクリックすると選択（破線枠）され、テンキー 1–4 で選択、 +/- で ±1 BPM、Shift+テンキー± で ±0.1、 *// で ±10（すべてグライド経由）。 ヘッダーの ◀▶ ステッパーでも選択トラックのBPMを 0.01 / 0.1 / 1 / 10 の 桁ごとに増減できる（長押しで連続、文字ボタンで選択切替）。
PHASE SCOPE は緑蛍光体のブラウン管: 低解像度ラスタを ピクセル拡大し、前フレームを消さずに減衰させることで残光（トレイル）を 作っている。
FX: 各トラックに共有リバーブへのセンドと、トラック専用のピンポン （L·R）エコー。エコーのタイムは 1/16〜1/2 の音価指定で そのトラック自身のテンポに追従する — 追いつかせの最中はエコーも一緒に うねる。FREE を選ぶ（または TIME ノブを回す）とテンポから切り離れ、 TIME ノブ（20ms〜2s）でマニュアル指定になる。FB はフィードバック量。録音のパラ・ステムはドライ信号のまま （FX はマスターにのみ乗る）。
FILL: ヘッダーの FILL（または F キー）で、各ドラムトラックの 次の小節頭から1小節、ランダム生成のフィル（6系統のテンプレート+揺らぎ）が 入り、自動で元のパターンに戻る。トラックごとに自分のテンポで入るので、 ポリテンポのままフィルが回る。
パターンメモリ: ドラムトラックは P1–P4 の4つのパターンを持ち、 ボタンで即切替（編集はスロットごとに保持、プロジェクトに保存）。
録音: RECORDER の REC（または R キー）で開始/停止。マスター （ソフトクリップ後・モニター音量前）と、PARA ON なら非ミュートの各トラック （トラックゲイン後・マスターチェーン前のドライ信号）を AudioWorklet で 同時キャプチャする。全ファイルは同一フレーム範囲で切り出されるため サンプル単位でアラインしている。WAV は 16/24/32bit float、AIF は 16/24bit。 RATE の変更は AudioContext を作り直すため停止中のみ（AUTO はデバイスレート）。 パラ録音では複数ファイルを連続ダウンロードするので、ブラウザが許可を 求めることがある。
PHASE SYNC の着地: 収束が終わった時点で両者の次の小節頭の時刻差 e を測り、 レイズドコサイン形のBPMの膨らみ（面積がちょうど e になる）を1回かける。 始点と終点でBPMは目標値に一致し、位相だけが e ぶん進む。 残差が閾値以下になったらステップ時刻をスナップしてロックする。
安全設計: 各トラック −12dB のヘッドルーム、マスターに 20Hz ハイパス → リミッター → tanh ソフトクリップ。起動時の音量は控えめ。
MIDI: 受け専用。LEARN を押してから操作子をクリックし、CC を動かすと割り当て。 割り当ては localStorage に保存される。MIDIクロックは1本しか流せないため、 4つの異なるBPMの同時送出は原理的に不可能。
保存: SAVE は JSON を書き出す。サンプルの音声データは含まれないので、 読み込み後にファイルを選び直す必要がある。
