A faithful Apple-Silicon-native reimplementation of the cyan/n ETR rhythm engine (Katsuhiro Chiba, Max/MSP, 2003–2007). The original standalone ships only PowerPC + 32-bit Intel code and cannot run on M-series Macs; this rebuilds its voices and effects from the extracted patch graphs in the browser. See EXTRACTION.md.
