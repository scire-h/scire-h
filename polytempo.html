ABOUT / 仕様メモ
テンポ: 各トラックは独立した連続BPMを持つ。スケジューラはWeb Audioの オーディオクロック基準（lookahead方式）で、1ステップの長さを テンポ曲線の数値積分（シンプソン則）で求めるため、テンポが動いている最中でも 位相がずれない。
BPMの変更: つまみ・手入力・MIDIどれで変えても即座には跳ばず、 CATCH-UP CONSOLE の CATCH RATE / CURVE に従って現在の再生テンポから グライドする（最大120秒）。グライド中にもう一度動かすと、その地点から 新しい目標へ再計画される。停止中は即時反映。
ピッチ: シンセ音源はシーケンサークロックの変速なのでピッチ不変。 サンプルは playbackRate = BPM / BASE BPM のテープ方式で、 テンポの揺れがそのままピッチのうねりになる。サンプルの TUNE つまみは BPMそのものを動かす（チューニング＝テンポの一部）。 音声ファイルにはBPM情報が無いため、読み込み時の BASE BPM は 120 とし、 FIT LOOP（サンプル全体＝ループ長とみなして算出）か手入力で合わせる。
音色エディット: 各トラックの VOICE EDIT で、シンセボイスごとに 波形（AUTO/SIN/TRI/SQR/SAW）・ピッチ（コードはカットオフ）・ディケイ・ サスティンを編集できる。AUTO はライブラリ本来の波形。各行はモノボイスで、 サスティンを上げた音は同じ行の次のヒット（CH と OH は相互）まで持続し、 新しいヒットが前の音をチョークする。停止時と8秒の安全上限でも解放される。 エディット値は 808/909 を切り替えても保持され、プロジェクトに保存される。
操作の要点: CATCH RATE は合流にかける時間（左=速い/右=遅い、 追従の途中で回すと再計画）。BPM SYNC はテンポのみ一致で小節頭はズレたまま並走、 PHASE SYNC は目標BPMを一瞬追い越して小節頭を合わせロックする。 ヘッダーの A–D でトラックの ON/OFF。グリッドはクリックのほか 押しながらスライドで連続入力（最初のセルで ON/OFF が決まる）。 トラックカードをクリックすると選択（破線枠）され、テンキー 1–4 で選択、 +/- で ±1 BPM、Shift+テンキー± で ±0.1、 *// で ±10（すべてグライド経由）。
FX: 各トラックに共有リバーブへのセンドと、トラック専用のピンポン （L·R）エコー。エコーのタイムは 1/16〜1/2 の音価指定で、 そのトラック自身のテンポに追従する — 追いつかせの最中はエコーも一緒に うねる。FB はフィードバック量。録音のパラ・ステムはドライ信号のまま （FX はマスターにのみ乗る）。
FILL: ヘッダーの FILL（または F キー）で、各ドラムトラックの 次の小節頭から1小節、ランダム生成のフィル（6系統のテンプレート+揺らぎ）が 入り、自動で元のパターンに戻る。トラックごとに自分のテンポで入るので、 ポリテンポのままフィルが回る。
パターンメモリ: ドラムトラックは P1–P4 の4つのパターンを持ち、 ボタンで即切替（編集はスロットごとに保持、プロジェクトに保存）。
録音: RECORDER の REC（または R キー）で開始/停止。マスター （ソフトクリップ後・モニター音量前）と、PARA ON なら非ミュートの各トラック （トラックゲイン後・マスターチェーン前のドライ信号）を AudioWorklet で 同時キャプチャする。全ファイルは同一フレーム範囲で切り出されるため サンプル単位でアラインしている。WAV は 16/24/32bit float、AIF は 16/24bit。 RATE の変更は AudioContext を作り直すため停止中のみ（AUTO はデバイスレート）。 パラ録音では複数ファイルを連続ダウンロードするので、ブラウザが許可を 求めることがある。
PHASE SYNC の着地: 収束が終わった時点で両者の次の小節頭の時刻差 e を測り、 レイズドコサイン形のBPMの膨らみ（面積がちょうど e になる）を1回かける。 始点と終点でBPMは目標値に一致し、位相だけが e ぶん進む。 残差が閾値以下になったらステップ時刻をスナップしてロックする。
安全設計: 各トラック −12dB のヘッドルーム、マスターに 20Hz ハイパス → リミッター → tanh ソフトクリップ。起動時の音量は控えめ。
MIDI: 受け専用。LEARN を押してから操作子をクリックし、CC を動かすと割り当て。 割り当ては localStorage に保存される。MIDIクロックは1本しか流せないため、 4つの異なるBPMの同時送出は原理的に不可能。
保存: SAVE は JSON を書き出す。サンプルの音声データは含まれないので、 読み込み後にファイルを選び直す必要がある。
