CATCH RATE は合流にかける時間。左に回すほど速く、右に回すほどゆっくり追いつく。 追従の途中で回すと、その時点から新しい時間で再計画される。
BPM SYNC はテンポだけ一致（小節頭はズレたまま並走）。 PHASE SYNC はテンポを合わせたあと目標BPMを一瞬追い越して小節頭を合わせ、 一致した瞬間にロックする。

ABOUT / 仕様メモ
テンポ: 各トラックは独立した連続BPMを持つ。スケジューラはWeb Audioの オーディオクロック基準（lookahead方式）で、1ステップの長さを テンポ曲線上で中点法により数値積分して求めるため、テンポが動いている最中でも 位相がずれない。
ピッチ: シンセ音源はシーケンサークロックの変速なのでピッチ不変。 サンプルは playbackRate = BPM / BASE BPM のテープ方式で、 テンポの揺れがそのままピッチのうねりになる。サンプルの TUNE つまみは BPMそのものを動かす（チューニング＝テンポの一部）。
PHASE SYNC の着地: 収束が終わった時点で両者の次の小節頭の時刻差 e を測り、 レイズドコサイン形のBPMの膨らみ（面積がちょうど e になる）を1回かける。 始点と終点でBPMは目標値に一致し、位相だけが e ぶん進む。 残差が閾値以下になったらステップ時刻をスナップしてロックする。
安全設計: 各トラック −12dB のヘッドルーム、マスターに 20Hz ハイパス → リミッター → tanh ソフトクリップ。起動時の音量は控えめ。
MIDI: 受け専用。LEARN を押してから操作子をクリックし、CC を動かすと割り当て。 割り当ては localStorage に保存される。MIDIクロックは1本しか流せないため、 4つの異なるBPMの同時送出は原理的に不可能。
保存: SAVE は JSON を書き出す。サンプルの音声データは含まれないので、 読み込み後にファイルを選び直す必要がある。
